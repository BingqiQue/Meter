# 测光 / Meter

SwiftUI + AVFoundation 原生 iPhone 测光与场景记录 App，最低 iOS 17，竖屏使用，无第三方依赖。

## 运行

1. 使用完整 Xcode 26 或更新版本打开 `Meter/Meter.xcodeproj`。
2. 在 Meter target → Signing & Capabilities 中选择自己的开发团队，工程中的签名设置为开发环境配置；请使用自己的团队和唯一 Bundle Identifier。
3. 选择 iPhone 真机，运行并允许相机访问。模拟器不能验证实时测光或拍照。
4. 点击参数数值进入滚轮选档。每个数值下方有独立锁定按钮：点“已锁定”将该项设为自动；点自动项的“锁定”将它固定，并让上一自动项恢复自动。始终保持两项锁定、一项自动。调整自动项数值也会将其固定。
5. 主界面固定为一屏，不上下滚动。取景下方提供“原生 / 35 / 50 / 85 / 100”快捷焦距，表示 35mm 等效视角；点击后当前镜头执行裁切缩放，预览和照片同时生效。快门右侧 EV 按钮打开曝光补偿面板。
6. 焦距栏下方可切换全画面、中央区域、点测光；点测光可点击取景移动区域。实际可选模式由当前镜头能力决定。
7. 按快门记录，预览中选择白色或黑色边框，再保存或分享。缩略图可重新打开最近一张照片。

最低部署版本为 iOS 17，工程包含 AppIcon 资源。各模式的实景测光表现、保存和分享仍需进一步真机验收；尚未配置 App Store 发布流程。

## 实现

- `Exposure.swift`：独立曝光模型、常用档位、三种求解与 EV 平滑。相机读数每 150ms 更新；低通滤波、约 0.24EV 滞回及三分之一档量化减少跳动。
- `CameraService.swift`：串行队列管理相机、权限、切换、会话中断和照片代理。使用自动曝光，闪光灯关闭。iOS 26 及支持区域测光的镜头使用原生 `exposureRectOfInterest`：全画面为 100% 画幅、中央区域默认 50% × 50%、点测光默认 10% × 10%，尺寸不小于镜头声明的最小区域。显式区域模式关闭人脸优先自动曝光，避免覆盖所选区域。用户的建议参数从不写入摄像头硬件设置。
- `MeterView.swift`：固定主界面，按安全区域高度给工具栏、焦距栏、模式栏、状态、参数和快门预留固定空间，取景使用剩余高度；曝光补偿移至快门右侧入口。参数滚轮、照片预览和设置仍为独立面板。
- `PhotoExport.swift`：快门时建议曝光值快照按 capture ID 关联照片；处理 EXIF 方向，完整照片下方增加边框。同一渲染 UIImage 用于预览及 JPEG 保存/分享。只申请相册添加权限。

快捷焦距使用当前物理广角镜头的 `videoZoomFactor = 目标等效焦距 / 原生等效焦距`，不会伪装成光学镜头切换。iOS 26 优先使用 `nominalFocalLengthIn35mmFilm`；旧系统按视频水平视场角与画幅比例匹配 36×24mm 对角线视角。考虑镜头校正后选择对应视场角。界面将结果标为“约 … mm · 等效”，不支持的焦距置灰，避免静默限制倍率却仍显示目标焦距。每次切换前后相机重新计算范围；选中焦距若不再可用，回到原生。变焦后测光点回中，读数清空并重新稳定，建议参数锁定状态不变。

估算公式：

`EV100 = log2(N_camera² / t_camera × 100 / ISO_camera) + exposureTargetOffset`

`N_suggested² / t_suggested = 2^(EV100 + calibration - compensation) × ISO_suggested / 100`

曝光目标偏差采用当前曝光相对相机目标的偏差；正曝光补偿增加建议曝光，正校准增加估算场景 EV、减少建议曝光。使用原始计算值判定越界，再限制到档位范围并选择最近常用档位。档位范围：1/8000–30s、f/1–f/32、ISO 25–25600。

取景框使用预览层坐标转换显示实际配置的测光区域，点击位置也由预览层转换为设备坐标，因此兼容竖屏、前置镜头镜像及 aspect-fit 黑边。切换模式或镜头会清空读数并等待约 350ms 后继续采样。旧系统／不支持区域测光的镜头只提供“自动测光”及可用时的“选点参考”，后者区域大小由系统决定。中央区域不是传统中央加权算法，全画面也不是自定义矩阵测光算法。自动曝光读数无法可靠识别所有局部高光溢出；低光、较大曝光目标偏差和建议档位越界会提示。不同镜头和手机的计算摄影行为可能带来偏差，未声明专业测光精度。建议参数与最终手机照片的实际曝光可能不同。

照片保留在内存中，最近一张会在应用终止后丢失；请保存或分享。导出的 JPEG 包含拍摄内容和建议参数文字，不携带原图 EXIF/GPS。白黑边框偏好独立于浅深色主题并持久保存。

## 验证

纯计算测试不依赖 iOS SDK，覆盖曝光求解、81 组锁定序列、固定值保持、测光模式能力降级与区域边界，以及等效焦距换算、缩放上下限、未知焦距和旧系统视场角估算：

```sh
swiftc -module-cache-path /tmp/meter-swift-cache Meter/Sources/Exposure.swift Meter/Tests/main.swift -o /tmp/meter-exposure-tests
/tmp/meter-exposure-tests
```

在完整 Xcode 环境验证构建：

```sh
xcodebuild -project Meter/Meter.xcodeproj -scheme Meter -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

真机验收：

- 分别拒绝、允许相机权限，拒绝后从设置恢复；切后台再返回、系统打断后恢复。
- 三种测光模式分别对比亮暗目标，点测光点击画面边缘及前置镜像画面，确认框和实际区域一致；切换镜头检查模式降级。
- 三种自动参数逐一验证；调整任一固定值，确认另外一个固定值不变；滚轮反馈、快速切换及范围边界。
- 改变光线后自动值稳定跟随；低光、强光、遮镜头、镜头切换后不沿用旧读数。
- 拍照后立即改变光线与建议参数，确认边框仍然显示按快门瞬间的值。
- 前后摄像头拍照，确认图像方向正确、无裁切；白黑边框在浅深色主题下成品一致。
- 相册添加权限拒绝、允许，以及分享取消、分享完成；检查相册保存的 JPEG 与预览一致。
- 小尺寸 iPhone、较大辅助字体、VoiceOver、连续拍摄和高分辨率照片内存表现。
- 主界面上下拖动无滚动，快门始终可见；曝光补偿面板和数值滚轮正常打开。
- 35 → 100 → 50 → 85 → 原生依次切换，确认视角改变、选中状态准确，拍照与取景一致；切换前后相机、后台恢复后倍率与可用档位同步。

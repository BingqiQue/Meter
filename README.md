# 测光 / Meter

一款使用 SwiftUI 和 AVFoundation 开发的原生 iPhone 测光与场景记录 App。通过手机相机估算场景亮度，在快门、光圈和 ISO 中锁定两项，计算第三项的建议值，并将建议曝光参数与照片一起保存。

适合随手测光、记录拍摄现场，以及为独立相机的曝光设置提供参考。

## 功能

- **实时测光**：显示 EV 与建议曝光，使用平滑和三分之一档量化减少读数跳动。
- **两项锁定、一项自动**：快门、光圈、ISO 可通过滚轮选档，并独立切换锁定状态。
- **区域测光**：支持全画面、中央区域和点测光；实际可用选项取决于系统与镜头能力。
- **等效焦距预览**：原生、35、50、85、100 mm 快捷选项；不可用档位自动置灰。
- **曝光调整**：支持曝光补偿和测光校准。
- **场景记录**：拍摄照片，选择黑色或白色边框，附上按下快门时的建议曝光参数，再保存到相册或通过系统分享。
- **界面设置**：支持浅色、深色、跟随系统以及取景网格。

无第三方依赖，无需注册账号，测光和照片处理均在本机完成。

## 运行项目

1. 克隆或下载仓库，在仓库根目录执行：

   ```sh
   open Meter/Meter.xcodeproj
   ```

2. 在 Xcode 中选中 **Meter → Signing & Capabilities**，选择自己的开发团队。其他开发者请将 Bundle Identifier 改为自己的唯一标识。
3. 选择连接的 iPhone，运行 App。
4. 首次使用时允许相机访问；保存照片时再允许添加照片到相册。

工程包含开发环境的签名设置，不包含签名私钥或发布证书。无需安装 CocoaPods 或额外的 Swift 包。

## 使用方法

1. 将取景框对准需要测量的场景，等待读数稳定。
2. 点击快门、光圈或 ISO 的数值调整档位，通过下方按钮锁定其中两项，让第三项自动计算。
3. 根据场景选择测光模式。在点测光或选点参考模式下，可点击取景画面移动测量位置。
4. 选择等效焦距以调整取景范围；使用快门旁的 EV 按钮设置曝光补偿。
5. 按下快门记录场景，在照片预览中选择边框并保存或分享。

最近一张照片可以从缩略图重新打开。照片不会自动保存到相册，结束 App 前请手动导出。

## 测光与拍照的区别

**界面和照片边框中的数值是建议曝光参数，可能与手机照片的实际拍摄参数不同。** App 使用手机相机的自动曝光读数估算亮度，不会将用户选择的快门、光圈和 ISO 写入相机硬件设置。

- 手机型号、镜头、计算摄影处理和光照环境可能影响读数，本项目尚未进行专业测光精度标定。
- 中央区域测光使用矩形曝光区域；全画面模式和中央区域模式不等同于独立相机的矩阵测光、中央加权算法。
- 旧系统或不支持区域测光的镜头会降级为自动测光，以及可用时的选点参考。
- 等效焦距快捷选项使用当前镜头的裁切缩放，不代表切换到对应焦距的光学镜头。
- 自动曝光读数无法可靠识别所有局部高光溢出，低光环境建议多次测量。

参数范围：快门 **1/8000–30 s**、光圈 **f/1–f/32**、ISO **25–25600**。

## 权限与数据

- **相机权限**：用于实时测光和场景拍摄。
- **相册添加权限**：仅在保存时申请，用于添加导出的照片。
- App 不包含账号、分析统计或照片上传服务；系统分享的目的地由用户选择。
- 最近的场景照片保存在内存中，App 结束后不会保留；分享时生成临时 JPEG 文件。
- 导出的 JPEG 包含照片内容和建议参数文字，不复制原始照片的 EXIF/GPS 元数据。

## 验证

本次检查环境：Xcode 27.1。计算测试与 Debug 模拟器构建均已通过；真机功能仍需单独验收。

以下命令均在仓库根目录运行。

### 计算测试

使用 macOS Swift 工具链运行，无需 iPhone：

```sh
swiftc -module-cache-path /tmp/meter-swift-cache \
  Meter/Sources/Exposure.swift Meter/Tests/main.swift \
  -o /tmp/meter-exposure-tests
/tmp/meter-exposure-tests
```

覆盖曝光求解、补偿与校准方向、参数越界、读数滤波、81 组锁定序列、测光能力降级、区域边界、等效焦距换算和变焦范围。

### 模拟器构建

```sh
xcodebuild -project Meter/Meter.xcodeproj \
  -scheme Meter -sdk iphonesimulator -configuration Debug \
  -derivedDataPath /tmp/meter-derived-data \
  CODE_SIGNING_ALLOWED=NO build
```

计算测试和编译检查不代表真机功能验收。权限恢复、前后镜头、区域测光效果、照片保存与分享等仍需按 [开发文档](docs/DEVELOPMENT.md#验证) 在真机上验证。
